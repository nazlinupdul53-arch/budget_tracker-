# My Budget Tracker

## About the Project

My Budget Tracker is a simple web application created to help users manage and keep track of their daily expenses. It allows users to enter an expense name, choose a category, enter the amount, and organize their expenses in a table.

## Files in the Project

### index.html

This file contains the main structure and content of the Budget Tracker. It includes:

* The main page heading
* The Add Expense form
* Expense categories
* The expense table
* The Budget Plan section
* Budget tips
* Media content

### style.css

This file controls the visual appearance of the Budget Tracker. It includes:

* A consistent color palette
* Google Fonts for headings and body text
* Styled forms and input fields
* Styled buttons
* Expense table styling
* Borders, margins, and padding
* Rounded corners
* Alternating table row colors
* Card-style sections
* Hover and focus effects

### README.md

This file provides information about the project, its files, design features, and technologies used.

## Design Features

The project uses a purple, lavender, white, and light background color palette. Playfair Display is used for headings, while Poppins is used for the main body text.

The Add Expense form and Expense Table are designed with proper spacing, padding, borders, rounded corners, and consistent colors. These features give the Budget Tracker a clean, organized, and user-friendly appearance.

## Technologies Used

* HTML
* CSS
* Google Fonts
